Create a Widget

Everything you need to write, test and publish a community widget.

A community widget is a single .cs file written in C# 5. It compiles against the running app, so there are no dependencies to install and no project file to manage. If you can draw with GDI+ and write a class, you can make a widget.

Before you start

Install Desk Widgets
You need the app running to load your widget. Download it from the home page or the Microsoft Store.
Pick a text editor
Any editor works. Visual Studio or VS Code with the C# extension will give you autocomplete, but Notepad is fine too.
No NuGet, no SDK
Widgets compile with the .NET Framework compiler built into Windows. No SDK download is needed.

The smallest widget

Start with this. It draws a dark rounded rectangle and says hello.

using System;
using System.Drawing;
using System.Drawing.Drawing2D;
using DeskWidgets;

[DeskWidget(Name = "Hello", Description = "The smallest community widget")]
public sealed class HelloWidget : WidgetWindow
{
    public HelloWidget(Section s) : base(s) { }

    protected override Size Measure()
    {
        return new Size(Px(170), Px(170));
    }

    protected override void Draw(Graphics g)
    {
        g.SmoothingMode = SmoothingMode.AntiAlias;
        g.Clear(Color.Transparent);
        int r = Px(22), w = Px(170);
        using (var path = new GraphicsPath())
        {
            path.AddArc(0, 0, r * 2, r * 2, 180, 90);
            path.AddArc(w - r * 2 - 1, 0, r * 2, r * 2, 270, 90);
            path.AddArc(w - r * 2 - 1, w - r * 2 - 1, r * 2, r * 2, 0, 90);
            path.AddArc(0, w - r * 2 - 1, r * 2, r * 2, 90, 90);
            path.CloseFigure();
            using (var b = new SolidBrush(Color.FromArgb(28, 28, 30)))
                g.FillPath(b, path);
        }
        using (var f = new Font("Segoe UI Semibold", 20f, GraphicsUnit.Pixel))
            g.DrawString("Hello", f, Brushes.White, Px(16), Px(16));
        using (var f = new Font("Segoe UI", 13f, GraphicsUnit.Pixel))
            g.DrawString(DateTime.Now.ToString("HH:mm"), f,
                Brushes.Gray, Px(16), Px(44));
    }
}

Save this as HelloWidget.cs, then in the app go to Installed > Install from File… and pick the file. The widget appears on your desktop.

Key concepts

Two base classes

Every widget extends one of these:

WidgetWindow
The low-level base. You get a Graphics surface and draw everything yourself. Use this when you want full control over rendering (the Hello example above uses it).
CardWidget
Extends WidgetWindow with Apple-style card drawing: rounded rectangle, dark/light/vibrant palettes, DPI-aware sizing, font caching, emoji support, and text helpers. Most community widgets use this.

Attribute

Mark your class with [DeskWidget]. The Name is what users see in the library and the Description appears below it.

[DeskWidget(Name = "My Widget", Description = "One line about what it shows")]
public sealed class MyWidget : CardWidget { ... }

Constructor

The constructor receives a Section (the widget's settings bag). Pass it to the base class. For CardWidget, the second argument says whether the widget is full-bleed (picture widgets like Photo Frame pass true; most pass false).

public MyWidget(Section settings) : base(settings, false) { }

Drawing

Override DrawContent(Graphics g, Palette pal) for CardWidget, or Draw(Graphics g) for WidgetWindow. The card base handles the background, rounded corners and size. You draw the content inside.

protected override void DrawContent(Graphics g, Palette pal)
{
    Label(g, "Hello", F(15, "semibold"), pal.Fg, P(16), P(24));
    Label(g, DateTime.Now.ToString("HH:mm"), F(11, "regular"),
        pal.Fg2, P(16), P(48));
}

Sizes

CardWidget supports three sizes: small (170 × 170 pt), medium (364 × 170 pt) and large (364 × 382 pt). The base class handles measuring and DPI scaling. Use P(pt) for point-to-pixel conversion and W / H for the current size in pixels.

Settings

Read and write settings through Settings, the INI-backed bag the constructor receives.

string city = Settings.Get("city", "London");
Settings.Set("city", "Paris");

int count = Settings.GetInt("count", 0);
bool on = Settings.GetBool("dark", true);

Animation

Return a positive number from NextFrameDelay() and the app will call Draw again after that many milliseconds. Return -1 when there is nothing to animate. Call Render() to request a single redraw on demand.

protected override int NextFrameDelay()
{
    // Redraw once a minute for a clock.
    return 60000 - DateTime.Now.Second * 1000;
}

Context menus

Override BuildWidgetMenu(PopupMenu menu) (CardWidget) or BuildMenu(PopupMenu menu) (WidgetWindow) to add items to the right-click menu.

protected override void BuildWidgetMenu(PopupMenu menu)
{
    menu.Add("Refresh", delegate { LoadData(); });
    menu.AddCheck("Dark Mode", isDark, delegate { isDark = !isDark; Render(); });
    var sub = menu.AddSubmenu("Interval");
    sub.AddChoice("1 min", interval == 1, delegate { interval = 1; });
    sub.AddChoice("5 min", interval == 5, delegate { interval = 5; });
}

Background work

Never block the UI thread. Use the Background helper to run work off-thread and receive the result on the UI thread.

Background(() => {
    // Runs on a background thread.
    return Http.GetString("https://api.example.com/data");
}, (result, error) => {
    // Runs on the UI thread.
    if (error == null) { data = result; Render(); }
});

HTTP requests

The Http helper provides simple GET and POST methods that return strings or bytes.

string json = Http.GetString("https://api.example.com/data");
byte[] image = Http.GetBytes("https://example.com/photo.jpg");

A CardWidget example

This widget shows a greeting and the current time, with a right-click option to change the name.

using System;
using System.Drawing;
using DeskWidgets;
using DeskWidgets.Widgets;

[DeskWidget(Name = "Greeting", Description = "Says hello by name")]
public sealed class GreetingWidget : CardWidget
{
    public GreetingWidget(Section settings) : base(settings, false) { }

    string Name { get { return Settings.Get("name", "World"); } }

    protected override int NextFrameDelay()
    {
        return 60000 - DateTime.Now.Second * 1000;
    }

    protected override void DrawContent(Graphics g, Palette pal)
    {
        float m = P(16);
        Label(g, "Hello, " + Name, F(17, "semibold"), pal.Fg,
            m, P(24));
        Label(g, DateTime.Now.ToString("dddd, h:mm tt"),
            F(13, "regular"), pal.Fg2, m, P(52));
    }

    protected override void BuildWidgetMenu(PopupMenu menu)
    {
        menu.Add("Change Name…", delegate
        {
            string input = InputDialog.Show("Name", Name);
            if (input != null)
            {
                Settings.Set("name", input);
                Render();
            }
        });
    }
}

Testing your widget

Install from file
In the app, go to Installed > Install from File… and pick your .cs file. The widget compiles and appears on your desktop.
Edit and reload
Change your file, then right-click the widget and choose Reload. The app recompiles and redraws it without removing it.
Check all three appearances
Right-click > Appearance and test Dark, Light and Vibrant. Use pal.Fg, pal.Fg2 and pal.Bg instead of hard-coded colors so all three look right.
Try every size
If your widget supports small, medium and large, test all three. Use W and H to lay out content relative to the current size.

Publishing

When your widget is ready for others to use:

1. Create an account
Sign in on this site. You need an account to upload.
2. Go to Upload
Visit the Upload page. Fill in the widget ID (a short unique slug like greeting), pick a category, and paste your source code.
3. Add a preview image
Upload a screenshot of your widget (PNG or JPEG, max 1200 px on the longest side). This is what people see in the gallery.
4. Wait for review
Every version is read by a person before it appears in the gallery. You will see the status on your profile page.

Rules

One file, C# 5
Your widget is a single .cs file. No C# 6+ features (no string interpolation, no null-conditional, no expression-bodied members). It compiles with the .NET Framework 4 compiler built into Windows.
No file system writes
Widgets should not write to disk outside of the cache directory returned by CacheFile(name). Use Settings for configuration.
Stay light
Desk Widgets runs in about 33 MB with seven widgets. Don't allocate per frame. Run network and disk work on background threads. Check IsCovered() and skip frames when the widget is behind other windows.
No bundled binaries
Everything must be in your source file. You can use any namespace from the .NET Framework and System.Drawing, but no external DLLs.

API reference

These are the main types your widget can use. Their source is in the repository.

WidgetWindow
Base class. Override Measure(), Draw(Graphics), NextFrameDelay(), BuildMenu(PopupMenu), OnWidgetClick(Point). Properties: Settings, Dpi. Methods: Render(), Px(logical), IsCovered(), Background(work, done).
CardWidget
Extends WidgetWindow. Override DrawContent(Graphics, Palette) and BuildWidgetMenu(PopupMenu). Helpers: P(pt), W, H, F(pt, weight), Label(), Paragraph(), FillCircle(), FillRound(), RoundRect(), CacheFile(name), CardPath(). Palette fields: Bg, Fg, Fg2, Fill, Sep, Red, Orange, Green, Blue, Purple.
Section
Get(key, default), GetInt(key, default), GetBool(key, default), Set(key, value), Remove(key).
PopupMenu
Add(label, action), AddCheck(label, checked, action), AddSubmenu(label) (returns a PopupMenu), AddChoice(label, selected, action).
InputDialog
InputDialog.Show(prompt, defaultValue) — returns the entered string or null if cancelled.
Http
GetString(url), GetBytes(url), PostString(url, body, contentType). All blocking — call from a background thread.
PluginApi
DataDir (the app data folder), Protect(plain) / Unprotect(stored) for DPAPI encryption, CalendarEvents and CalendarChanged for shared calendar data.
